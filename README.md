# OrganoLeaf 통로 설계 시뮬레이터

2026 체인지메이커 OrganoLeaf 팀의 탐구용 웹 시뮬레이터입니다. 혈관 구조가 부족한 오가노이드를 가정하고, 직선형 통로와 잎맥형 분기 통로가 조직 안 물질 공급 범위와 농도 균일성에 어떤 영향을 주는지 같은 조건에서 계산합니다.

외부 계산 서버 없이 브라우저에서 실행됩니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구성(조건 설정, 지도, 그래프, 표 자리) |
| `css/style.css` | 디자인(색, 배치, 다크 모드) |
| `js/core.js` | 계산 모델: 구조 생성, 거리 계산, 농도 확산, 지표, 판정, 검증 (화면 코드 없음) |
| `js/worker.js` | 자동 탐색 등 오래 걸리는 계산을 백그라운드에서 돌리는 Web Worker (`core.js`를 불러옴) |
| `js/leafwater.js` | 10번 잎 모양 물 확산 모델(팀 시뮬레이터) |
| `js/app.js` | 화면 동작: 조절 막대, 지도·그래프 그리기, 비교표, 탐색 결과 해석, 이전 분석 기록 |

계산식을 고치려면 `js/core.js`만 고치면 됩니다. 화면과 Worker가 같은 파일을 쓰므로 두 곳의 계산이 항상 같습니다.

## 실행 방법

- **GitHub Pages(권장)**: 폴더 전체를 저장소에 올리면 Web Worker까지 정상 작동합니다.
- **내 컴퓨터에서 확인**: 폴더에서 `python -m http.server` 실행 후 `http://localhost:8000` 접속(또는 VS Code의 Live Server).
- `index.html`을 더블클릭해 직접 열면(file://) 브라우저가 Worker를 막는 경우가 있습니다. 이때는 같은 계산을 화면 쪽에서 대신 하므로 결과는 같지만, 자동 탐색 중에는 화면이 잠시 멈출 수 있습니다.

## 기능

1. **조건 설정**: 총길이, 직선형 통로 수(자동 가능), 입구 조건(입구 1개 + 매니폴드 / 직선형 개별 입구), 분기 각도, 측맥 쌍 수, 세맥 분기점 수, 통로 굵기, 거리 기준. 두 구조의 총길이 차이를 화면에 표시(허용 1%).
2. **거리 지표**: 평균 거리, 최대 거리, 거리 기준 이내 비율(10 μm 격자, 기존 방식).
3. **농도 확산 모델**: ∂C/∂t = D∇²C − kC (명시적 유한차분). 통로 내부 농도 모델 A(일정) / B(입구에서 멀수록 exp(−s/Lₛ)로 감소). 시간 슬라이더·재생, 농도 지도와 목표 도달 시간 지도.
4. **농도 지표**: 목표 농도 이상 영역 비율, 판정 기준 도달 시간(미도달 구분), 미도달 비율, 평균 농도, 변동계수(균일성), 통로 1 mm당 목표 이상 면적, 입구 연결 통로 비율.
5. **자동 비교표**: 지표별 잎맥형 우세 / 직선형 우세 / 비슷함 판정(비슷함 기준 기본 5%, 0 근처는 절대 기준).
6. **자동 조건 탐색**: 한 변수씩 전체 탐색(9개 변수, 40개 조건) 또는 두 변수 히트맵. Web Worker로 계산, 진행률 표시, 결과 해석 자동 생성(계산 결과 / 가정 / 추정 구분), CSV 내려받기.
7. **검증**: 거리 손계산 비교, 정상 상태 해석해 비교, 안정 조건, 물질 보존, 재현성, 격자 수렴(40·20·10 μm).
8. **직접 그리기**, **이전 분석 기록(거리 지표, 2026. 10. 29.)**.
9. **잎 모양 물 확산 모델(10번 섹션)**: 팀이 만든 '잎맥 물 확산 시뮬레이터'를 계산식 변경 없이 옮김(원래 코드와 결과 일치 확인). 맥 총길이·맥 부피 지표, 조직 퍼짐 시간 식 선택(거리 비례 / 거리² 비례), 검토 의견 추가. 1~8번과는 다른 도달 시간 모델이므로 숫자를 바로 비교하지 않음.

## 주요 기본값과 근거

| 항목 | 기본값 | 근거 |
|---|---|---|
| 조직 크기 | 2 mm × 2 mm | 기존 값(교육용 설정) |
| 거리 격자 | 10 μm | 기존 값 |
| 통로 굵기 | 20 μm | 기존 값(교육용 설정) |
| 농도 격자 Δx | 20 μm | 계산 시간·정확도 절충(교육용 설정), 격자 수렴 확인으로 점검 |
| 확산계수 D | 2000 μm²/s (2×10⁻⁹ m²/s) | 세포 속 산소 확산계수 문헌값(arXiv:2501.12095, Grimes 외 2014 인용) |
| 소모율 k | 0.089 /s | λ = √(D/k) = 150 μm(문헌 확산 한계 100~200 μm의 중간)이 되도록 역산한 교육용 설정값 |
| 목표 농도 / 판정 기준 | 0.3 C₀ / 조직의 50% | 교육용 설정값 |
| 계산 시간 T | 60 s | 약 5/k |
| 모델 B 감소 길이 Lₛ | 2000 μm | 교육용 설정값 |

## 한계

- 2차원 정사각형 조직, 확산 + 1차 소모만 계산합니다. 유량, 압력, 혈류, 대류는 계산하지 않습니다.
- 모델 B의 통로 내부 농도 감소는 가정한 식입니다.
- 직접 그리기는 거리 지표만 계산합니다.

## GitHub Pages 배포 방법

1. 저장소에 `index.html`, `README.md`, `css/`, `js/` 폴더를 올립니다(기존 `index.html` 교체).
2. **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 `main` / `(root)`로 둡니다.
3. 몇 분 뒤 `https://<사용자이름>.github.io/<저장소이름>/`에서 확인합니다.
